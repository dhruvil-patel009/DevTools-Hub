# Portfolio Content — DevTools Hub

- **Project Name**: DevTools Hub
- **Short Description**: Privacy-first full-stack developer utility workspace with 50 tools, Auth.js accounts, admin management, and optional Gemini AI assistance.
- **Problem Statement**: Developers rely on scattered, ad-heavy online tools that often transmit sensitive JSON, JWTs, or code to third-party servers.
- **Proposed Solution**: A unified, keyboard-first workspace executing 47 core tools locally in the browser with optional cloud persistence and consent-gated AI tools.
- **Technology Stack**: Next.js 15, React 19, TypeScript, Tailwind CSS v4, Monaco Editor, Zustand, TanStack Query, Prisma, PostgreSQL, Auth.js v5, Gemini API, Vitest, Playwright, Docker.
